# un-bien

Mobile remote control and local agent mesh for the
[Pi coding agent](https://github.com/earendil-works/pi): a native iOS/macOS
client that pairs to your machine over a relay, watches tool calls in real time,
and drives Pi from your phone — plus a local agent mesh so multiple Pi sessions
(and agents) can talk to each other.
