# Bundled fonts

Drop `.ttf`/`.otf` files here to ship them with the app — they're registered at
launch by `FontLibrary` and appear in Settings → Appearance → Mono font.

For **MesloLGS Nerd Font**: download from <https://www.nerdfonts.com/font-downloads>
(the `Meslo.zip` release), unzip, and copy the `MesloLGS NF *.ttf` files here.
Or add them at runtime via Settings → **Import font…** (no rebuild needed).
