# App Store release notes — 1.6.0 (build 26)

What's New text, App Store "What's New" field / TestFlight build notes.
Everything since 1.5.5 (build 25).

## iOS + macOS

- Tool results now look like what they are, live and when reopened: shell
  output, highlighted files, real diffs with line numbers, search matches,
  scripts with their calls and output, and formatted web pages and agent
  reports. Failed calls show why. No more raw JSON.
- New Settings → Tool results: choose whether each kind of tool card
  starts open, as a short preview, or closed.
- Preview shows the last lines of shell output and the first lines of a
  read or search, with a tap to see the rest.
- Card headers name the file and line range, URL or task a call acts on.
- A jump-to-end button appears while you're scrolled away from the newest
  messages.
- Durable sessions render their tool results just like pi sessions.
- Steadier scrolling: card heights are estimated much more closely.

## One-liner (if a single field is preferred)

Tool results that read like what they are, per-kind display settings with
pi-style previews, and a jump-to-end button.
